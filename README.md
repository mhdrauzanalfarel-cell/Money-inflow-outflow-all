# 💰 CASHFLOW — Crypto + Real Life Tracker

A personal finance tracker that combines **crypto wallet activity** and **real life cash flow** in one place.

## Features
- 💎 Track multiple crypto wallets (ETH balance, USD equivalent)
- 🔥 Log mint expenses & swap-to-USDT income
- ⛽ Track gas fees & bridge costs
- 💳 Manual real life entries (Dana, cash, daily expenses)
- 📊 Dashboard with net balance breakdown
- 🕐 Full transaction history with filters

## Tech
Pure HTML + React (CDN) — no build tools, runs directly in browser.
